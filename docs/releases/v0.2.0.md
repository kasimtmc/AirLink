The first public release of AirLink: a link between your Linux, Windows and Android devices on your own network, with no account and no cloud.

**Downloads**

| Platform | File | Notes |
|---|---|---|
| Linux | `AirLink-0.2.0-x86_64.AppImage` | Runs on most distributions with glibc 2.39 or newer (Ubuntu 24.04, Fedora 40, Debian 13 and later). `chmod +x` and run. |
| Linux | `airlink_0.2.0_amd64.deb` | Ubuntu 24.04+ and Debian 13+, with the KDE panel widget. |
| Linux | `AirLink-0.2.0-x86_64.flatpak` | Experimental: call audio over Bluetooth doesn't work inside the sandbox. `flatpak install --user AirLink-0.2.0-x86_64.flatpak` |
| Linux | `AirLink-0.2.0-linux-x86_64.tar.gz` | The binary with `packaging/install.sh` (menus, file-manager entries, KDE panel widget). |
| Linux | `AirLink-0.2.0.plasmoid` | The KDE Plasma 6 panel widget for the AppImage, tar.gz or Flatpak (the .deb has it already): `kpackagetool6 --type Plasma/Applet --install AirLink-0.2.0.plasmoid`, start AirLink once, then add **AirLink** to the panel. |
| Windows | `AirLink-0.2.0-windows-x64-setup.exe` | Per-user installer, no administrator needed. |
| Windows | `AirLink-0.2.0-windows-x64.zip` | Portable; also holds the packaged install for Bluetooth call audio (`install-package.cmd`, Developer Mode). |
| Android | `AirLink-0.2.0-android-arm64.apk` | Android 7.0+, 64-bit ARM. |

`SHA256SUMS` lists the files' checksums.

**What it does**

- Files and folders between paired devices: drag and drop, the share sheet, Explorer/Dolphin/GNOME Files menus, or a fling of the phone.
- The clipboard, with a history; trusted devices get it automatically, and copied passwords ask first.
- Phone notifications, SMS and calls on the computer, with a dialer and the call log.
- The phone's screen and its apps in windows on the computer; phone audio over Bluetooth.
- The phone's battery and "find my phone".
- A tray panel (and a KDE panel widget) for all of it without opening the window; starting at login.

Linux and Android are tested on real devices, Windows and the Flatpak less so. Report problems in the issues.
